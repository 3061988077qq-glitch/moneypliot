iPhone 安装方式

MoneyPilot 不是 App Store 安装包，而是 PWA。请用 iPhone Safari 打开本页或 App 页面，然后添加到主屏幕。

  1. 1
    用 Safari 打开网页

    访问测试链接，或在同一 Wi-Fi 下打开你电脑提供的临时地址。

  2. 2
    点击分享按钮

    在 Safari 底部或顶部工具栏点击分享图标。

  3. 3
    添加到主屏幕

    选择“添加到主屏幕”，确认名称后即可像 App 一样打开。

给其他 iOS 用户测试

这个页面现在只用于测试分发。你可以把测试包临时放到任意 HTTPS 静态空间，或让同一 Wi-Fi 下的 iPhone 打开你电脑上的本地测试地址。

HTTPS 测试链接

适合测试“添加到主屏幕”和离线缓存，分享链接给 iPhone 用户即可。

同 Wi-Fi 临时测试

适合快速打开页面体验功能；普通 HTTP 局域网地址不保证可安装。

测试包

运行 npm run package:ios-test 生成 zip，里面包含介绍页和 App。
